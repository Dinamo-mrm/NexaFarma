# 🏥 NexaFarma

> **Sistema de Gestión de Inventario, Ventas y Pedidos para una Farmacia**
> Proyecto formativo - SENA (Servicio Nacional de Aprendizaje)

## 📖 Descripción del Proyecto
**FarmaSoft Plus** es una aplicación web integral desarrollada para optimizar y asegurar las operaciones de una farmacia. El sistema permite administrar clientes, empleados, proveedores, inventario, compras, ventas y fórmulas médicas. Destaca por su control riguroso de aspectos propios del sector farmacéutico, como la gestión de lotes, fechas de vencimiento, registros sanitarios (INVIMA) y el manejo de medicamentos controlados frente a los de venta libre.

## 🚀 Módulos y Características Principales

* **👥 Gestión de Usuarios y Roles:** Sistema de autenticación seguro con control de acceso por perfiles (Administrador, Farmacéutico/Regente, Vendedor, Auxiliar de farmacia).
* **📦 Control de Inventario y Lotes:** Seguimiento en tiempo real de entradas y salidas. Sistema de alertas automáticas para stock bajo y productos próximos a vencer, incluyendo el bloqueo preventivo de lotes vencidos.
* **💊 Gestión de Medicamentos:** Catálogo detallado con soporte para categorías, clasificación de venta libre o bajo prescripción, requerimientos de refrigeración y control de registros sanitarios.
* **🛒 Compras y Ventas:** Flujo completo desde la orden al proveedor hasta la facturación al cliente (exportable a PDF). Actualización automática del inventario tras cada transacción.
* **📝 Fórmulas Médicas:** Registro, validación de vigencia y asociación de recetas para restringir la venta de medicamentos controlados sin prescripción.
* **🚚 Devoluciones y Domicilios:** Gestión integral de logística inversa y seguimiento de pedidos a domicilio en sus distintos estados (preparación, en camino, entregado).
* **📊 Dashboard y Reportes:** Panel de control interactivo con métricas clave diarias (ingresos, clientes, alertas) y exportación de informes estratégicos a PDF y Excel.

## 🛠️ Stack Tecnológico

El proyecto está diseñado bajo una arquitectura en capas (Entity, Repository, Service, Controller, View, Security, Exception) garantizando escalabilidad y un manejo global de excepciones.

**Backend:**
* Java
* Spring Boot (Spring MVC, Spring Data JPA, Spring Security)
* Hibernate
* Bean Validation
* Lombok (opcional)

**Frontend:**
* HTML5, CSS3, JavaScript
* Bootstrap

**Base de Datos:**
* MySQL

**Herramientas & Pruebas:**
* Maven / Gradle
* JUnit, Mockito, MockMvc
* Postman (API Testing)

## ⚙️ Metodología de Desarrollo
El ciclo de vida del software se rige por la metodología ágil **Scrum**, distribuyendo el trabajo en iteraciones y asignando roles clave para asegurar entregas continuas y de valor.
